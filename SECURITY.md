# Security policy

## Reporting a vulnerability or privacy issue

Do not open a public issue for security vulnerabilities, exposed secrets, personal-data leaks or confidential client information.

Report them privately to [william.jolivet@epitech.eu](mailto:william.jolivet@epitech.eu) with:

- a concise description of the issue;
- the affected file, workflow or release;
- reproduction steps when applicable;
- the potential security or privacy impact.

Reports will be acknowledged as soon as practical. Please avoid accessing, modifying or redistributing data beyond what is necessary to demonstrate the issue.

## Supported version

Only the current `main` branch and the latest published release are supported.
